# Rokonujjaman Reon Portfolio

A responsive, single-page portfolio website built with vanilla HTML, CSS, and JavaScript.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## Setup

No dependency installation is required.

```bash
git clone https://github.com/RokonujjamanReon/portfolio.git
cd portfolio
```

## Development

Open `index.html` in a browser for quick iteration, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Build

This project is a static site and does not require a compilation build step.

## Deployment

Deploy as static files (`index.html`, `style.css`, `script.js`) to any static host, for example:

- GitHub Pages
- Netlify
- Vercel (static)

## Customization

Update the structured content in `/script.js` (`portfolioData`) to edit skills, projects, timeline entries, and social links.
